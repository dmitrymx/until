# Until

Сайт: https://dmitrymx.github.io/until/

Личные отсчёты до любого события: своя картинка, живые плитки, русский и английский, тёмная и светлая тема.

Регистрация не нужна. Список хранится в браузере на этом устройстве. На другое устройство он переносится файлом копии — вместе с картинками. Ссылка на одно ожидание открывается где угодно и несёт название, дату и адрес картинки, если он указан.

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга:

```bash
npm run build
```

Папка `dist` — это готовый статический сайт. Её можно выложить на Cloudflare Pages, Netlify или GitHub Pages. Отдельный сервер не нужен: адреса живут в ссылке после `#`.
